# 🇮🇳 COVID-19 India Data Analysis

An exploratory data-analysis project examining historical COVID-19 reporting across India with Python.

## Analytical questions

- How did reported cases change over time?
- Which states recorded the highest reported burden?
- How did confirmed, recovered and deceased counts compare?
- What patterns appear in daily reported changes?
- How did recovery and fatality rates vary?

## Workflow

`Raw Data → Cleaning → Exploration → Aggregation → Visualisation → Insight`

## Tech stack

**Python · Pandas · NumPy · Matplotlib · Jupyter Notebook**

## Skills demonstrated

- Data cleaning and preparation
- Exploratory data analysis
- Time-series analysis
- Grouping and aggregation
- Rate calculations
- Data visualisation
- Communicating analytical findings

## Run locally

```bash
git clone https://github.com/Akr0333/COVID19-India-Data-Analysis.git
cd COVID19-India-Data-Analysis
python -m venv .venv
.venv\\Scripts\\activate
pip install -r requirements.txt
jupyter notebook
```
